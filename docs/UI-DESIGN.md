# UI 设计规范（网页管理端）

依据 [Ludi-Herry/mobile-design-system-skill](https://github.com/Ludi-Herry/mobile-design-system-skill)
的六步工作流与三大红线落地：视口 `viewport-fit=cover`、安全区物理避让、44/48dp 触控热区、
软键盘防遮挡、底部抽屉三分屏与滚动穿透阻断。下面记录本项目的具体实现。

从 Android/Compose 迁到网页后，界面规范按 iOS HIG 的移动端惯例落地：
**留白优先、层级靠背景而不是描边、动效克制**。本文只记录本项目的执行口径。

## 硬门禁与本仓库的对应实现

| 规范条款 | Web 落地 |
| --- | --- |
| 顶部避让状态栏/灵动岛 | 页面容器 `pt-[max(1rem,env(safe-area-inset-top))]` |
| 底部避让 Home Bar / 手势条 | 悬浮底栏 `pb-[max(16px,env(safe-area-inset-bottom))]`；输入条 `.safe-bottom` 同样取下限 16px |
| 软键盘不遮挡输入 | 视口 `viewport-fit=cover`；聊天输入条贴底，键盘弹起时由浏览器自动上推 |
| 最小触控热区 44×44 | 主按钮 `h-12`、行内按钮 `min-h-[44px]`、列表行 `min-h-[48px]`，图标按钮补 `aria-label` |
| 相邻可点项留白 ≥8dp | 列表行内部 `gap-3`；底栏项之间 `gap-1` 加内边距 |
| 细分隔线 | `--sep` 变量，浅色 `rgb(0 0 0 / .07)`，深色 `rgb(255 255 255 / .1)`；网页按 1px 渲染 |
| 3–5 槽位底栏 | 会话 / 机器人 / 设置，悬浮玻璃胶囊，选中态用品牌色底 |
| 空态与失败出口 | 每个列表都有空态文案；断线时顶部常驻说明条并自动重连 |
| 同心圆角 | 卡片 `--radius-card`，内部按钮 12–16，气泡 18 |
| 单一主 CTA | 配对页只有一个全宽「连接」按钮 |

## 桌面模式

宽度 ≥768px 时不再拉伸手机布局：

- 左侧固定 228px 导航栏，底部胶囊隐藏；
- 会话页变成「列表 360px + 聊天窗」双栏，没选会话时右栏给引导态；
- 机器人与设置走单栏，内容居中限宽 780px，不跟着窗口无限铺开；
- 列表行补 `hover` 态，触控与鼠标两套反馈都在；
- 聊天页隐藏「返回」按钮，改用列表点击切换。

## 抽屉与输入

- 抽屉用 `Sheet`：顶部拖拽条、最高 85vh、内容区独立滚动；
- 打开时给 `body` 加 `sheet-open` 锁死底层滚动与手势，关闭时移除；
- 表单类抽屉不响应遮罩点击，只能用「取消」或 Esc 关闭；
- 输入框聚焦时 `scrollIntoView({block:'center'})`，键盘弹起不会盖住输入位置；
- 数字类输入统一 `inputMode="numeric"`，手机号类用 `tel`。

## 视觉语言

- **背景分层**：页面底色 `--bg`，卡片 `--bg-elevated`，按下态 `--bg-sunken`。
  用背景差表达层级，不靠投影；只有悬浮底栏带一层柔和投影。
- **强调色**：单一品牌蓝 `--accent`，只用于主按钮、选中态、未读数。
- **文字层级**：34px 加粗大标题（iOS 大标题）、16px 正文、13px 次级、11–12px 辅助。
- **玻璃**：底栏与聊天页头部用 `backdrop-filter: saturate(1.8) blur(24px)`，
  底下必须有滚动内容才有意义，不要铺在纯色背景上。
- **动效**：只在首屏与面板出现时用 220ms 的 `rise`，不做滚动视差、不做循环动画。
- **深浅色**：只跟随系统 `prefers-color-scheme`，深色背景是纯黑（OLED 省电），
  卡片用 `#1c1c1e` 提亮一级。

## 新增界面时必须自查

1. 顶部与底部是否避让了安全区？
2. 每个可点元素热区是否 ≥44px？相邻项是否留够间距？
3. 键盘弹起时输入框与主按钮是否仍可见？
4. 分隔线是否 1px 半透明？圆角是否内外同心？
5. 空列表、断网、超时是否都有明确文案与操作出口？
6. 一屏是否只有 1 个全宽主按钮？

## 与协议的关系

- 界面只按 `caps` / `constraints` 渲染，不内置平台假设；
  QQ 的「被动回复 5 分钟窗口」由 `constraints.reply_window_s` 驱动，聊天页头部显示倒计时。
- 「当前活跃机器人」是客户端本地状态，切换不重连。

## Flutter 客户端的落地

`manager/lib/ui/tokens.dart` 把上面的颜色/字号/圆角固化成 `LColors` 与 `LiantTheme`，
`widgets.dart` 提供大标题页、分组卡片、玻璃底栏、抽屉等通用件：

- 34px 大标题用 `SliverPersistentHeader` 实现：滚动时从 34px 收到 20px 并吸顶，
  折叠后补 0.5px 底边；
- 会话列表按「今天/昨天/本周/更早」分组，组内一张 20px 圆角卡片，行高 ≥64，
  分隔线缩进 68 避开头像；
- 悬浮底栏用 `BackdropFilter` 24px 模糊 + 卡片色 72% 透明度，外面一圈柔和投影；
  底栏上缘离屏幕底 16px，再加 `MediaQuery.padding.bottom`；
- 聊天页头部同样用玻璃，滚动超过 24px 折叠掉副标题与回复窗口倒计时；
- 输入条、发送键、返回、备注都保证 ≥44px 热区；群聊在气泡上方显示发送者；
- ≥768px 改成 228px 左侧导航，内容限宽 780；底栏隐藏；
- 备注、已读、主动消息开关存本地；未读与断线状态都有文案与「立即重试」出口；
- 深色仍是纯黑背景 + `#1c1c1e` 卡片，跟随系统。

已知差距：宽屏「列表 360 + 聊天窗」双栏还没做，先留到下一轮。

## 自查结果

最近一轮按上面的条目逐条核对，修掉了这些：

- 发送键、启动/停止、吊销按钮原来 32–36px，低于 44px 热区，已抬高；
- 三级文字 `#a1a1a8` 在白底约 2.6:1，达不到 4.5:1，改成 `#6f6f76`；
- 配对页原来有两个全宽按钮，现在只有「直接进入」是主 CTA，配对码降为次级；
- 补了 `:focus-visible` 外框，键盘用户能看到焦点；
- 图标按钮补 `aria-label`。

仍然已知的差距：暂无。新增界面时继续按「自查」六条走。
