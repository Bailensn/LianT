# QQ 群管理接口能力清单（qbot 已接入的）

官方文档：<https://bot.q.qq.com/wiki/develop/api-v2/autogen/>

| 能力 | 接口 | 状态 | 前提 | 对应功能 |
| --- | --- | --- | --- | --- |
| 发送群 Markdown 卡片 | `POST /v2/groups/{gid}/messages`（`msg_type=2`） | ✅ 公开（自定义 Markdown 自 2026-04 起全量开放） | 机器人是群成员；主动消息受频控 | 网页「群消息」卡片群发 |
| 撤回群消息 | `DELETE /v2/groups/{gid}/messages/{mid}` | ✅ 公开 | 机器人是群管理员才能撤他人消息；限 2 分钟内 | 违禁词自动撤回、群内「引用消息 + 撤回」、网页手动撤回 |
| 设置群成员禁言 | `POST /v2/groups/{gid}/restrict_chat_setting` | ✅ 公开 | **机器人须是群管理员**；单次≤20 人；最长 30 天 | 违禁词禁言、群内「禁言 @某人 10分钟」、网页禁言 |
| 查询群禁言状态 | `GET .../restrict_chat_setting` | ✅ 公开 | 同上 | 网页显示当前禁言名单 / 全员禁言模式 |
| 机器人群内状态 | `GET .../bot_state` | ✅ 公开 | — | 自动记录「机器人是否群管理员」，决定能否禁言/撤回 |
| 入群申请列表 | `GET .../join_request_list` | ✅ 公开 | 机器人是群管理员 | 网页「入群申请」页 |
| 入群申请审批 | `POST .../approval_join_request/{mid}` | ✅ 公开 | 同上 | 网页通过/拒绝（拒绝可顺带拉黑）、`join_auto_approve` 自动通过 |
| 群成员批量移除（踢人） | `POST .../batch_remove_members` | ⚠️ **仅白名单机器人** | 平台运营开通（错误码 11253） | 群内「踢 @某人」「踢黑 @某人」、网页踢出 |
| 群黑名单增删查 | `GET/POST .../member_blacklist` | ⚠️ 同上 | 同上（且目标不在群内才能拉黑） | 「踢黑」、网页黑名单 |
| 群成员列表 / 成员信息 | `GET .../members[/{mid}]` | ⚠️ 同上 | 同上 | 网页群成员页 |
| 群基本信息 | `GET .../info` | ⚠️ **仅白名单机器人** | 30 QPM；返回群名/简介/人数，**没有头像字段** | 网页自动补全群名 / 显示群名人数 |

> 群信息接口没有头像字段，成员接口也没有头像；网页里的群/成员头像是按名称生成的配色首字，不是 QQ 头像。

> 网页「群消息」默认发送 Markdown 卡片（`markdown.content`，无需模板 ID），正文支持标题、加粗、列表、链接、引用和分割线；也可以切纯文本。主动消息频控：每个群约 20 条/分钟、1000 条/天，失败原因会显示在网页上并写入审计。

**拿不到白名单也不残废**：本地黑名单与禁言记录先落库并立刻生效 —— 黑名单成员的消息不回 + 尽量撤回；违禁词可配置「撤回 / 禁言 / 拉黑（本地）」；只有「真·踢出群聊」必须 QQ 侧权限。失败原因会原样写进审计和回复里（例如 `11253 → 该接口仅白名单机器人可用`）。

## 事件里能拿到什么（指令目标定位的基础）

| 字段 | 用途 |
| --- | --- |
| `mentions[]` | 消息里 @ 的人（openid + 昵称），不含 @机器人 自身 → 最常用的目标来源 |
| `author.username` / `author.member_role` | 每条消息都带昵称与群内角色（member/admin/owner）→ 机器人自建群名册、识别群管理员 |
| `message_scene.ext.ref_msg_idx` | 引用的是哪条消息 → 配合「最近消息缓存」反查出可撤回的消息 ID |
| `msg_elements[]`（type=103） | 引用消息的作者与内容 → 引用定位目标 |

## 部署前要做的两件事

1. **每个群里把机器人设为管理员**，否则禁言/撤回他人消息会返回 `40062003`。
2. 想用**踢人/拉黑/群成员列表**，去 QQ 开放平台联系运营申请白名单（`11253`）。
